## 底盘运动（电机驱动 + 麦轮解算 + PS2 遥控）

### 功能描述

底盘需满足手册「底盘运动·单一/全部」与「电机运动·单一/全部」两项基础功能指标：
- 能使用 PS2 手柄控制**全部车体**的水平运动（平移 / 横移 / 自转），演示需车体与手柄同时出镜或附代码。
- 至少 4 个电机可转动。
- 通用约束：初始尺寸 ≤290×195×210mm、任意可变 ≤445×400×450mm（或 550mm 球约束）、≤2.0kg；每台仅 1 个供电模块 ≤7.4V。

### 开发历程

- **现状（10-09）**：`motor.c`、`mecanum.c`、`ps2` 为雏形，需确认是否可编译、是否已整机联调。
- **P1 现状体检（10-09~11）**：读 `motor.c/mecanum.c/ps2`，列"已实现/半实现/未实现"清单；核对 `final.ioc` 引脚分配；确认 4 路电机 PWM 频率、正反转与限幅参数。
- **P2 机械落地（10-10~14）**：麦轮×4 + TT 马达×4 + DRV8833 装配，紧固件锁紧；用直尺/称重校核 CAD 尺寸与重量。
- **P3 电控完善（10-12~17）**：
  - 打磨 `motor.c`：4 路驱动、PWM 频率、正反转、限幅。
  - 完善 `mecanum.c`：麦轮运动学解算（平移/横移/自转速度分配）。
  - 打通 `ps2`：手柄摇杆/按键映射到底盘，确认锁定款对频稳定。
  - 优化 `freertos.c`：底盘/遥控任务调度稳定，无死锁。
- **验收**：PS2 控制整车全向运动可演示（电机运动·全部 / 底盘运动·全部）。

## 机械臂与舵机控制

### 功能描述

满足手册「舵机运动·单一/多项」指标：同一台机器人至少 3 个舵机可转动，且可动机构能在**任意非初始状态下保持相对静止**。机械臂用于拾取方块（30×30×30mm）。

### 开发历程

- **现状（10-09）**：CAD 含机械臂骨架（`work2/work3.f3d`）；`servo` 模块雏形。
- **P1 校核（10-09~11）**：确认机械臂关节数 ≥3 且任意非初始姿态能自锁/保持静止（选型与结构决定）；确认 3D 打印件清单。
- **P2 装配（10-10~14）**：MG995×3 骨架 + SG90 夹爪装配，验证 4 舵机均可动；加固关节与末端。
- **P3 完善（10-12~17）**：打磨 `servo` 角度控制与夹爪开合；验证任意非初始姿态保持静止（舵机运动·多项）。
- **验收**：≥3 舵机转动 + 静止保持可演示。

## 方块携带（收集机构）

### 功能描述

满足手册「方块携带·单一/多项」指标：至少一台机器人**自主**使至少 1 块地面静止方块（30×30×30mm）由**非携带→携带**状态；多项要求携带 1 块后再自主携带另一块。

### 开发历程

- **现状（10-09）**：`pickup.c` 雏形，未验证。
- **P2 结构**：机械臂末端（夹爪/抱取）能稳定抓起 30×30×30mm 方块，夹取力度与行程可调。
- **P3 完善（10-12~17）**：打磨 `pickup.c` 方块携带逻辑；与底盘/机械臂协同；调夹爪开合。
- **验收**：先冲"单一携带"（首选），再冲"多项携带"（连续夹取 2 块）。

## 遥控与通信（PS2）

### 功能描述

手册要求：遥控器为官方物资表中的 PS2 手柄（可对频锁定款）；通讯方式三选一（蓝牙 / 2.4G / WiFi / 红外），发射源与接收源唯一；若用其他款式手柄造成失控**后果自负**。

### 开发历程

- **P1（10-09~11）**：核实现有 PS2 是否为**锁定款**（日志待确认项），必要时更换；确定通讯方案。
- **P3（10-12~17）**：`ps2` 模块完善，按键/摇杆映射到底盘与机械臂；验证对频稳定、无串频。
- **注意**：不携带干扰对方通信设备、不采用相近频段。

## 供电与结构安全（通用技术规范）

### 功能描述

满足手册通用/设计技术规范：18650 电池、单供电模块 ≤7.4V、尺寸/重量限制、结构强度（180mm 自由下落无零件掉出）、布线合理少裸露、适配官方无线继电器（10m 遥控断电，中期通过后购买）。

### 开发历程

- **P1（10-09~11）**：确认 18650 选型（官方表无链接，自购）；核对供电拓扑（仅 1 个供电模块）。
- **P2（10-10~14）**：18650×2 → DC-DC 5V → 主控/舵机/驱动；布线接插件化；**尽早做 180mm 跌落测试**（检录项，别留到最后）。
- **P5（10-20~23）**：无线继电器安装并测试 10m 遥控断电（中期通过后采购）。

## 视觉与自主收集（进阶功能）

### 功能描述

进阶功能（可选加分，最多 3 项，创新度/难度/完成度各 3 分取均值）——**需先完成全部基础功能**。候选：自动寻方块收集、能量核心定点取放、全自动/半自动模式（得分可×1.5–2）。

### 开发历程

- **现状（10-09）**：`vision.c` 雏形 + `tools/vision_sim.py` 仿真工具。
- **P3 后（10-17 之后，如基础功能已稳）**：打磨 `vision.c`，实现识别并自动靠拢夹取；录制可作为进阶加分项。
- **验收**：视频材料能明确判定该进阶功能被实际完成。

## 开源项目使用说明

> 依据手册文档规范：如使用开源项目用于机器人制作或代码编写，须在文档末尾完整说明，并遵守所使用开源项目的开源协议。

- **FreeRTOS**：用于 STM32 多任务调度（随 STM32CubeMX 集成）。开源协议：MIT。用途：底盘/遥控/机械臂任务并发调度。
- 其余模块（`motor / mecanum / pickup / vision / ps2 / servo / robot / debug`）为队伍自研，未引入第三方开源库。
- 若后续引入其他开源项目（如视觉库），将在本板块补充出处、协议与用途。
